# 基调与版式规范

## 基调不只是配色

同时确定：语言风格、信息密度、图文比例、标题语气、色彩和留白。用户说“别花哨”时，默认浅底深字、稳定网格、少量强调色、无动画；不把“高级”理解为重装饰。

| ID | 名称 | 默认气质 | 适用 |
| --- | --- | --- | --- |
| academic-blue | 学术白蓝 | 严谨、证据优先、少量蓝色 | 论文、开题、答辩 |
| business-slate | 商务灰蓝 | 务实、结论与决策明确 | 工作汇报、项目评审 |
| warm-neutral | 温和米白 | 清晰、温和、不显冷硬 | 教学、复盘、交流 |
| quiet-green | 沉稳青绿 | 稳定、技术感但不过度装饰 | 技术方案、工程汇报 |
| ink-mono | 黑白极简 | 居中封面、无底色分栏 | 极简汇报、内容评审 |
| classic-burgundy | 学院酒红 | 宋体标题、细框分栏 | 人文社科、正式答辩 |
| slate-indigo | 理性靛蓝 | 浅底封面信息区、冷静层次 | 方法说明、数据分析 |

这些不是内容限制：相同基调可用于多个场景。用户可组合“商务布局 + 米白色调”，或直接给品牌色。默认正文不使用整段强调色。

## 自定义

例如用户说：“米白背景、深灰正文、暗绿色重点；严谨但别太冷，不要动画。”助手应同时：

1. 把颜色映射到 `background/text/muted/accent/surface`；检查对比度。
2. 把语言要求写进 `tone_notes` 并落实到页面标题和备注。
3. 保持内容页稳定栅格；封面可以稍有变化，但不突然切换另一套设计。
4. 用相同内容提供 2–3 张样页确认，不用空白色卡代替版式预览。

生成器的 `custom_tone` 处理视觉令牌，不能自动理解 `tone_notes`；自然语言基调需要助手在内容编辑阶段落实。

除了颜色和正文 `fontFace`，还可分别自定义：`titleFontFace`（标题字体）、`coverLayout`（classic 左对齐 / centered 居中 / panel 浅底信息区）、`panelStyle`（filled 浅底分栏 / outline 线框 / none 仅留白）。可把任一预设与这些参数组合；内容页正文始终优先左对齐，不因封面居中而全部居中。

```json
{
  "tone": "custom",
  "tone_notes": "温和但严谨，注重方法证据，留白充足",
  "custom_tone": {
    "name": "米白青绿",
    "background": "FAF8F3",
    "text": "28332F",
    "muted": "5B625C",
    "accent": "35614F",
    "surface": "EDF0E7",
    "fontFace": "Microsoft YaHei"
  }
}
```

颜色使用 6 位 HEX，不带 `#`。代码拒绝正文、辅助文字、强调色与背景的低对比组合；这只是最低护栏，不能替代投影检查。

## 排版

- 默认宽屏 13.333 × 7.5 英寸；边距约 0.6 英寸，内容区与页脚分离。
- 标题 32pt 左右，封面 40pt 左右；正文 22–24pt。图表/表格标签 18pt 左右；页码和来源可用 11–14pt。
- 一页一个论点。相邻信息组使用一致间距。不要把多个完整段落装进几张小卡片。
- 对照用双栏，方法用示意图，证据用图表，计划用步骤；不是每页都放四格卡片。
- 长标题分成两行或简化；文字放不下就拆页或改编排，不能无提示截断。
- 默认无纹理、阴影、渐变、动画或背景音乐。装饰必须有信息用途。

## 视觉与数据

- 数据图使用真实数值，轴从合理起点开始，说明单位和统计口径。
- 科研图片优先完整显示，图注写清来源。复杂图需局部放大时保留总览或说明裁剪。
- 用原生可编辑表格/图表；已有实验图无法重建数据时嵌入原图并如实说明编辑边界。
- 无资料时使用“待提供/待验证”，不能用演示数值混入成品。基调样张可以使用明确标注的说明性示例。

## 样页与验收

随附 preview 命令生成十二组样页，默认每组三页：封面、要点、双栏，共 36 页。采用相同内容便于比较，且不包含虚构研究结果。选择时先推荐与用途匹配的 3 种，再按需查看更多；无需用户逐一回答 12 个问题。该样张是 PPTX 本身，不是 HTML。

实际成品要检查目标电脑、中文字体替换、长标题、表格密度、图片清晰度、备注和附件打开行为。未安装 PowerPoint/LibreOffice 时交付真实文件并说明尚未渲染；不能声称“逐页视觉检查通过”。
